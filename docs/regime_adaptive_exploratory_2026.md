# Temporal Robustness and Regime-Adaptive Extension

This is a **post-freeze, retrospective research** extension to ProjectAgentTrading26.
The SMA200 defensive gate has an independent economic rationale and uses only
information available as of each historical decision. Its evaluation, however,
was conducted after inspection of the official 2022–2026 outcome; therefore it is
**not** a new independent holdout. The original Core35–Satellite65 metrics, code
freeze and archived NAVs remain unchanged.

## Commands (from repository root)

```bash
python main.py --analysis temporal-robustness
python main.py --analysis regime-adaptive
python main.py --analysis regime-adaptive --output-dir exploratory_outputs
python -m unittest discover -s tests -p 'test_exploratory_analysis.py' -q
```

No output CSV is created unless `--output-dir` is passed. Output paths inside
`reports/`, `data/`, `src/`, `tests/`, `docs/`, or `figures/` are prohibited.
If an output directory is desired in the repository, use the untracked
`exploratory_outputs/` folder; avoid broad `git add .` commands.

## Temporal robustness

The 2023--2026 figures are calculated from the **existing** daily portfolio
return series beginning in January 2022. Holdings are not reset at January
2023, no supervised model is refit, and no new backtest period is designated.
All sample windows are descriptive slices of the same archived evaluation.
The frozen Core returned **−20.787% cumulatively in 2022** (2022-segment CAGR
**−21.160%**) and **14.343% CAGR / 1.234 Sharpe / −10.035% MDD** during
3 January 2023–9 October 2026. The latter is *not* the result of retraining
RF/SVM/GA on data through 2022.

## Regime-adaptive extension

- For SPY close **at or above** its past-200-trading-session simple average,
  preserve the frozen Core35--Satellite65 target weights.
- For SPY close **below** that SMA200, apply the B_v2 positive 21/63-session
  momentum gate and require a +1 direction from the frozen agent Orchestrator
  for ETF eligibility, then run the existing frozen satellite selector.
- Preserve 35% SPY Core and nominal 65% single-asset Satellite, with the
  original **0.10 uniform volatility fallback**, confidence threshold **0.35**
  and hysteresis buffer **0.015**.
- Evaluate development (2010--2021) and retrospective previously seen
  2022--2026 on the same daily next-open execution engine and original costs.
- Both potential satellite selectors maintain independent hysteresis state.
  This is an explicit modeling assumption of the experiment, not a claimed
  property of the original frozen candidate.

This mode reuses the original `src/level_c_strategy.py` as the extension site,
`src/submission_runner.py` for read-only calculation and `main.py` as a CLI.
The scientific freeze lists 47 code/model/input files. None are edited here.
**This policy reuses the B/C *signal agreement* concept only**: it does not
implement standalone Level C's macro-budget allocation or its 126-session
covariance-based 8% ex-ante volatility constraint. Below-SMA200 weeks retain
35% nominal long SPY Core even when the satellite is flat.

## Observed results and statistical scope

| Policy | Development 2010–2021 CAGR | 2022–2026 CAGR | 2022–2026 Sharpe | 2022–2026 MDD |
|---|---:|---:|---:|---:|
| Frozen Core35–Satellite65 | 12.064% | 5.872% | 0.551 | −26.543% |
| B/C Long/Flat always on | 8.928% | 11.280% | 1.166 | −8.506% |
| **Regime-Adaptive SMA200** | **10.599%** | **9.805%** | **0.912** | **−12.802%** |
| Weekly 60/40 SPY/IEF benchmark | 10.859% | 7.388% | 0.694 | −19.840% |

SPY closed below its 200-session moving average on **83 of 626 development
decisions** and **58 of 249 retrospective OOS-period decisions**. The adaptive
variant had lower development CAGR and Sharpe than the frozen Core,
despite improved retrospective downside outcomes.

A simple SPY/SHY SMA200 comparator (outside the current `--analysis` CLI)
had approximately **9.814% CAGR and 0.881 Sharpe** over 2022–2026, close
to the adaptive system's return. This is evidence against attributing the
entire observed benefit to multi-agent complexity.

Separate exploratory regressions of adaptive daily returns on a comparator
and a constant (intercept annualized ×252; Newey–West/HAC standard errors,
5 lags; zero assumed risk-free rate) estimated:

| Comparator | Annualized regression intercept | p-value |
|---|---:|---:|
| SPY buy & hold | +2.55% | 0.344 |
| Weekly 60/40 | +3.66% | 0.200 |
| Frozen Core | +5.01% | 0.055 |

None is significant at 5%, and the p-values are **not** adjusted for
multiple inspected variants. These supplemental statistics were computed
from saved daily-return research files and are **not** generated by the
current `python main.py --analysis regime-adaptive` command or indexed in
the original 47-file/13-artifact scientific manifests. Reproducibility
requires retaining the supporting analysis CSV and a calculation script
with the final optional report or research appendix.

## Interpretation

The original candidate's full 2022--2026 CAGR remains 5.872%, Sharpe 0.551,
MDD -26.543%; neither this extension nor the temporal slice changes that
registered finding. Include experimental outcomes only as retrospective
analysis or supporting appendix, not a revised official OOS test.
