# Historical Research and Software Provenance

This final submission is a reproducible scientific snapshot. It preserves the
original pre-2022 selected Core35-Satellite65 strategy, archived market inputs,
GA and ML models, protected evaluation files, and separate retrospective
allocation studies.

The broader collaboration record remains identifiable in the Git repository
at commit `4f532686e0e921cb3712fe4e0733eecfa3475f26`. That historical
snapshot includes Gabriele Di Raimondo's original 2021-start Equal Active
backtests and visualisations, Giovanni Cafarelli's refactoring and tests, and
earlier development experiments. Those sources are **not** presented as the
validated 2022-2026 matched-replay code inside this ZIP.

The final ZIP is self-contained for the frozen Core evaluation and the included
Equal Active/SMA200 matched comparison. Broader development diagnostics and
collaboration chronology can be audited in the version-control history.
Scientific limitations and the distinction between the two backtest settings
are documented in `research_extensions_2026.md` and the final report.
